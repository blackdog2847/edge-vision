# edge-vision
Agentic AI Home Care Safety Net: Combining Edge Vision (YOLO) and Cloud LLMs for real-time fall detection and smart daily activity summarization.

🏠 Edge-Vision Agentic AI 防護網 (Home Care Safety Net)

本專案為新一代居家照護防護系統，採用 Edge-Cloud 協同架構設計，旨在為獨居長者與行動不便者提供全天候的智能守護。

✨ 核心功能與特色：

.邊緣視覺運算 (Edge Vision)：透過輕量化 YOLO 模型即時偵測人體姿態、跌倒事件與異常滯留，保障隱私且低延遲。

.Agentic AI 決策大腦 (Cloud LLM)：規劃整合 AMD-ITRI 雲端算力部署 LLM 代理人。Agent 將接手處理視覺端送來的事件，進行邏輯分析、自主過濾誤報，並能統整歷史數據。

.自動化作息摘要與互動：系統不僅提供緊急 Discord 警報，AI 代理人更會每日定時統整長輩作息，自動生成充滿溫度的「健康作息日報表」；家屬亦可透過 Discord 透過自然語言與 AI 進行雙向互動。

.彈性部署與隱私保護：支援動態危險區域劃設 (電子圍籬) 與一鍵隱私遮蔽模式。
